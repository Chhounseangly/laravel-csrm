# Contributing

Thank you for contributing to `seangly/laravel-csrm`.

## Development Setup

1. Install dependencies:
```bash
composer install
```

2. Run checks:
```bash
composer lint
composer analyse
composer test
```

## Pull Request Guidelines

- Keep changes focused and small.
- Add or update tests when behavior changes.
- Update documentation (`README.md` or `docs/*`) for user-facing changes.
- Update `CHANGELOG.md` under `Unreleased`.

## Commit Style

Use clear commit messages, for example:

- `feat: add api/web controller toggle`
- `fix: generate migration for --only=migration`
- `docs: update command usage`
